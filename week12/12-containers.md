For exam you should know the following about containers:

- What is a container?
  Containers are a lightweight form of virtualization that allows you to run applications in isolated environments. They share the host operating system's kernel but have their own filesystem, network, and process space.
- What are the benefits of using containers?
  - Portability: Containers can run consistently across different environments, making it easier to develop and deploy applications.
- Docker is a popular containerization platform that allows you to create, deploy, and manage containers. It provides a simple and efficient way to package applications and their dependencies into a single unit that can run anywhere.
- Kubernetes is an open-source container orchestration platform that automates the deployment, scaling, and management of containerized applications. It provides features like load balancing, service discovery, and self-healing to ensure that your applications run smoothly in a production environment.
- Containerization is widely used in modern application development and deployment, especially in microservices architecture, where applications are broken down into smaller, independent services that can be developed, deployed, and scaled independently. Containers help to improve the efficiency and scalability of microservices by providing a consistent and isolated environment for each service to run in.
