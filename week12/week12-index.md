# Week12: Deployment, Scaling, and Service-Approach
<SessionResources :week='12'/>
In week 12, we will cover the following topics:

- **Deployment**: Lifecycle of development to production, deployment options, and best practices.
- **Scaling**: How to handle increased traffic, load balancing, and performance optimization.
- **Service-Approach**: SAAS, PAAS, IAAS, and microservices architecture.
- **Version Control**: Using Git for code management, collaboration, and deployment workflows.
- **Continuous Integration/Continuous Deployment (CI/CD)**: Automating testing and deployment processes for faster and more reliable releases.
- **Containerization**: Using Docker to create, deploy, and run applications in containers for consistency across environments.
